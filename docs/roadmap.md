# Roadmap

This roadmap is directional and may change as the project receives real-world
feedback.

## v0.1.0-alpha — released 2026-09-17

- Provider-independent request and response models.
- A bounded synchronous runtime loop.
- Deterministic offline mock provider.
- Optional OpenAI Responses API adapter.
- Explicit tool registration and execution.
- In-memory runtime state.
- Offline tests, examples, documentation, and CI.
- First tagged alpha release.

## v0.2

- State serialization contract and pluggable persistence.
- One additional provider adapter selected from contributor demand.
- Async runtime interface and streaming design.
- Basic observability hooks and structured run events.

## v0.3

- Tool permission and confirmation policies.
- Evaluation fixtures and provider compatibility tests.
- Model routing experiments.
- Initial MCP integration design.

## Long term

- Durable memory and knowledge interfaces.
- Workflow orchestration.
- Enterprise isolation and business-context boundaries.
- Broader provider support, including local models.
- Operational observability, evaluations, and migration tooling.

Long-term entries are plans, not implemented features or release commitments.
